# Denny for Agents

**Маленький робот в вырезе MacBook, который присматривает за Claude Code и Codex.**

Разрешай действия агентов, смотри, что они делают, следи за лимитами тарифа и расходами — не отрываясь от работы.

## Что умеет

- 🤖 **Claude Code и Codex вживую:** каждая сессия в вырезе, по шагам — что читает, правит, запускает.
- ✅ **«Разрешить / Запретить» прямо из выреза.** Если Денни не запущен, агенты спрашивают в терминале как обычно — Денни их никогда не блокирует.
- 🖥️ **Агенты на серверах (SSH):** один проброшенный порт — и Денни на Mac видит агента на сервере.
- 📊 **Лимиты и расходы:** лимиты сессии и недели Claude и Codex, стоимость по ценам API, доля кэша, карта активности за 13 недель.
- ⏱️ **Живое число у камеры:** таймер текущей задачи или колечко самого полного лимита.
- 🔄 **Сбросы лимита Codex** из выреза, с подтверждением.
- 🔔 **Тихие уведомления:** только о долгих задачах, лимитах и дневном бюджете — каждое один раз.
- 📎 **Брось файл на вырез** — путь скопируется для агента, а если агент на сервере, файл уйдёт туда с твоим следующим сообщением.
- 🌍 **10 языков**, без аккаунта и телеметрии.

## Установка

1. Скачай `DennyForAgents.zip` в [Releases](../../releases), распакуй и перенеси **Denny for Agents.app** в «Программы».
2. Сборка пока не нотаризована Apple: при первом запуске открой **Настройки → Конфиденциальность и безопасность** и нажми **«Всё равно открыть»**.

Сборка из исходников, настройка сервера и подробности — в [английском README](README.md).
